# 稠密输出的首次气象阈值穿越与时刻灵敏度

步内水位多项式、越阈规则和分片时序。 仓库记录均为本地合成资料，不依赖外部数据服务。

## 数据约定

c 按从常数起的幂给值，局部时间为 (物理时刻 − start)/(end − start)。步左闭右开，指定监测区末端闭合。同一条轨迹在共享端点应连续到误差允许范围。已有数据只描述对应版本。

error 是参考真实轨迹相对名义多项式的逐时绝对误差上界。正式上穿须能把事件定位到不宽于 time_tolerance 的区间，区间之前能排除合格更早事件，区间右端起有连续 confirm 时长能证实在阈值之上。下穿对称，等于阈值本身不算越过。若误差带使结论不可证，给范围或未决。

种子对该已确认的名义多项式简根时刻求灵敏度，以当前轨迹修订参照。uncertain 为新轨迹替换的记录，delay 为旧轨迹片段到达顺序。

## 读取与核对

在 Python 3.11 环境执行 `python -m pip install -r requirements.txt` 安装数值依赖。
`python -m unittest discover -s tests -v` 读取 `data/exchange.json` 并核对资料结构与关键输入关系。
